# Changesets

Run `pnpm change` from the repository root when a change should be released. Select the affected packages, choose a patch, minor, or major bump, and describe the change for users. Commit the generated Markdown file with the change.

Changesets generates package changelogs directly. No custom changelog scripts are needed. Private packages, including the playground, are not versioned by Changesets v3.

See the [release workflow](../README.md#releases) and [Changesets documentation](https://changesets.dev/).
